# Card

[← Back to the README](../README.md)

Takes every `<div>` prop, including `ref`, plus:

| Prop           | Default |                                                                                        |
| -------------- | ------- | -------------------------------------------------------------------------------------- |
| `padding`      | `'md'`  | `'none'`, `'sm'` (12px), `'md'` (20px) or `'lg'` (32px).                               |
| `highlight`    | `true`  | Lights up the border near the pointer, even when the pointer isn't over the card.      |
| `innerSheen`   | `true`  | Shows a sheen inside the edges nearest the pointer while the pointer is over the card. |
| `refract`      | `true`  | Blurs what is behind the card and bends it at the edges.                               |
| `readableText` | `true`  | Automatic text colour (see [Readable text colour](colours.md#readable-text-colour)).   |

Its custom properties are listed under [Theming](theming.md).
